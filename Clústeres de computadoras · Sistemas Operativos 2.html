Teoría

¿Qué es un clúster y para qué sirve?

Un clúster es un conjunto de computadoras (nodos) conectadas por red que trabajan coordinadas y se presentan al usuario como un solo sistema. Se usa para tres propósitos: seguir funcionando aunque algo falle, atender más usuarios de los que soporta una sola máquina y resolver cálculos que un solo equipo tardaría días o años en terminar.

¿Cómo funciona a nivel de red y de sistema operativo?

Red

Los nodos se interconectan con switches Ethernet (1–100 Gb) o redes de baja latencia como InfiniBand. Suele haber una red de datos, una de administración y otra de heartbeat (latidos para detectar nodos caídos). Una IP virtual flotante permite que el servicio “migre” sin que el cliente note el cambio.

Sistema operativo

Cada nodo corre su propio SO (casi siempre Linux). Encima, un gestor de recursos (Slurm, Kubernetes, Pacemaker) decide en qué nodo se ejecuta cada proceso. Los procesos se comunican con paso de mensajes (MPI) o memoria compartida distribuida, y los nodos comparten datos mediante NFS, SAN o sistemas de archivos paralelos.

Retos para el SO

Sincronización sin reloj ni memoria comunes, consistencia de datos replicados, detección de fallos, split-brain (dos nodos creen ser el principal) y fencing (aislar al nodo que falló para proteger los datos).

Tipos de clúster

Alta disponibilidad (HA)

Nodos redundantes con failover: si el principal cae, otro toma su lugar. Meta: 99.99 % de disponibilidad o más. Ej.: bases de datos de un banco. Herramientas: Pacemaker, Corosync, Keepalived.

Balanceo de carga

Un balanceador reparte las peticiones entre nodos equivalentes. Escala horizontalmente y tolera fallos. Algoritmos: round robin, menos conexiones, hash de IP. Herramientas: HAProxy, Nginx, LVS.

Alto rendimiento (HPC)

Un trabajo se divide en tareas que se ejecutan en paralelo en cientos o miles de nodos. Meta: reducir el tiempo de cómputo. Herramientas: MPI, OpenMP, Slurm. Limitado por la ley de Amdahl: la parte secuencial no se acelera.

Ejemplos del mundo real

Supercomputadoras

Los sistemas del TOP500 (por ejemplo El Capitan o Frontier) son clústeres HPC con cientos de miles de núcleos para clima, física nuclear y simulación molecular.

Granjas web

Google, Amazon y Netflix reparten el tráfico entre miles de servidores con balanceadores en varias regiones; si un centro de datos cae, otro absorbe la carga.

Renderizado 3D

Los estudios de animación dividen una película en miles de cuadros y cada nodo de la render farm procesa algunos de ellos al mismo tiempo.
